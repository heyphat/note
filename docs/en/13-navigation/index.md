# Navigation

Most of the app is reachable from the keyboard alone. The mouse-friendly surfaces — sidebar, right dock, header — sit alongside that as visual reinforcement.

## In this section

- [Sidebar](./sidebar.md) — note tree, calendar strip, tag cloud, recent, templates, saved searches.
- [Right dock](./right-dock.md) — backlinks, history, project tasks.
- [Header toolbar](./header-toolbar.md) — quick toggles for the panels above.
- [File explorer](./file-explorer.md) — folder-level browsing and operations.
- [URL routing](./url-routing.md) — how the active note is reflected in the URL, browser back/forward.

For the keyboard-only path, see [Keyboard shortcuts](../15-keyboard-shortcuts.md). For finding content rather than navigating to it, see [Search](../06-search/index.md).

## Quick map

| Where | Shortcut | What it's for |
| --- | --- | --- |
| Sidebar | `Cmd/Ctrl + B` | Note tree, calendar, tags, recents, templates, searches |
| Command palette | `Cmd/Ctrl + K` | Find anything: notes, tags, actions |
| Right dock | `Cmd/Ctrl + Shift + B` | Per-note metadata: backlinks, history, project tasks |
| File explorer | `Cmd/Ctrl + Shift + E` | Folder navigation, create / rename / move |
| Graph | `Cmd/Ctrl + Shift + G` | Visual map of your wikilink graph |
| Vault tasks | `Cmd/Ctrl + Shift + K` | Every task in the vault, filterable |
| AI chat drawer | `Cmd/Ctrl + \` | Conversation with your AI provider |
| Zen mode | `Cmd/Ctrl + .` | Hide everything except the editor |
| Close active note | `Cmd/Ctrl + Shift + X` | Return to the empty state |
