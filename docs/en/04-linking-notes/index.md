# Linking notes

Notes get more useful when they reference each other. Note has four ways to express that: wikilinks, transclusion, the backlinks panel, and the graph view.

- [Wikilinks](./wikilinks.md) — `[[Other note]]`. The lightweight way to point one note at another.
- [Transclusion](./transclusion.md) — `![[Other note]]`. Embed another note's content inline.
- [Backlinks](./backlinks.md) — see every note that points *at* the one you're reading.
- [Graph view](./graph-view.md) — a visual map of your vault's link structure.

If you've used Roam, Obsidian, Logseq, or similar tools, the conventions are the same. If you haven't, start with [Wikilinks](./wikilinks.md) — every other feature in this section assumes them.
