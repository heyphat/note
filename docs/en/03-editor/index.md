# The editor

Note's editor is **WYSIWYG markdown** — what you type renders as you type, but the underlying file is plain markdown. It's built on Milkdown (the Crepe preset) on top of ProseMirror, with a few project-specific layers added on for callouts, wikilinks, transclusion, diagrams, and a slash-command menu.

You don't have to learn markdown syntax to use it. If you already know markdown, every shortcut you reach for (heading levels, lists, code fences, links) works.
