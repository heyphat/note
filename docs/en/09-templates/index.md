# Templates

A **template** is a reusable note skeleton. Pick one when you create a new note, and the editor starts from the template's body — with placeholders like `{{date}}` filled in for you.

Useful for any note you write repeatedly with the same shape: daily journal, meeting notes, weekly review, project kickoff, retro.

## In this section

- [Using templates](./using-templates.md) — picking a template when creating a note.
- [Template variables](./template-variables.md) — the placeholders that get interpolated.

## Where templates live

Templates are stored as ordinary `.md` files in your vault. Whichever folder you put them in is fine; the sidebar's **Templates** section lists every note flagged as a template (or, depending on your setup, every note in a designated templates folder).

This means a template:

- Is editable like any other note.
- Round-trips to other markdown tools.
- Can use any feature a note can — wikilinks, callouts, code blocks, even diagrams.

## When templates aren't worth it

If a note shape is one-off, just write it. Templates are most useful when you've already written the same skeleton three or four times and noticed yourself doing it.
